## Task 3 自研交互原型（已完成）

产物：`docs/prototype/index.html`（单文件自包含，96KB，无外部依赖）+ `docs/prototype/verify.js`（自检脚本）。

- 20 个屏，分 6 组：①账户认证（登录 / 邀请码注册 / 强制改密）②业务员 Android（首页离线态 / 入库卡片式 / 出库卡片式 / 历史与同步 / 结算申请）③桌面宽表（入库 / 出库 / 数据汇总 / 结算审批 / 付款收款开票 / 公司业务员总结算）④组内管理（成员 / 权限配置 / 邀请码 / 辅助字典）⑤平台治理 ⑥规则汇总。
- 交互能力：侧栏切屏（全部 `data-go` 元素统一委托）、浅/深色主题切换、chip 单选、手机底栏切换。
- 真算：宽表「数量 / 单价」单元格可编辑，JS 实时重算行金额（单价×数量）→ 分组小计 → 单据总额 → 人民币大写；出库分组小计、结算申请预览（进项合计 / 销售合计 / 毛利润）随勾选联动。
